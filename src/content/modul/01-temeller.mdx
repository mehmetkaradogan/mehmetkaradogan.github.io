## Hedef

Bu modülü tamamladığında agentic yapay zekanın (agentic AI) ne olduğunu, neden önemli olduğunu ve bir agent'ı oluşturan dört temel bileşeni anlayacaksın. Modülün sonunda çalışan bir Python ortamın ve Anthropic API ile yapılmış ilk mesaj alışverişin olacak.

## Önkoşullar

- Temel Python bilgisi (fonksiyon, liste, sözlük)
- Bir terminal / komut satırı deneyimi
- Python 3.11 veya üstü yüklü

## Öğrenme çıktıları

1. LLM ile agent arasındaki kavramsal farkı kendi cümlelerinle ifade edebilirsin.
2. Plan, araç kullanımı (tool use), hafıza (memory) ve yansıma (reflection) kavramlarını örneklerle açıklayabilirsin.
3. `python-dotenv` ve `anthropic` kütüphaneleri ile ortam kurabilir, API'ye ilk isteği gönderebilirsin.

## Adım 1 — LLM nedir, agent nedir?

Büyük dil modeli (LLM — Large Language Model), verilen bir metni tamamlayan istatistiksel bir sistemdir. Sana bir soru sorarsın, o bir yanıt üretir; iş biter.

**Agent** ise aynı LLM'i bir döngünün içine koyar:

```
Gözlemle → Planla → Eylem yap → Sonucu gözlemle → Tekrarla
```

Bu döngü sayesinde agent, tek seferlik bir yanıt üretmek yerine çok adımlı görevleri tamamlayabilir; araçlar kullanabilir, dosyaları okuyabilir, API çağırabilir ve kendi çıktısını eleştirebilir.

| Özellik | LLM | Agent |
|---|---|---|
| Hafıza | Yalnızca bağlam penceresi | Kısa + uzun vadeli hafıza |
| Eylem | Metin üretir | Araç çağırır, dosya yazar |
| Döngü | Tek yönlü | Geri-beslemeli döngü |
| Hata düzeltme | Yok | Yansıma (reflection) ile olabilir |
| Otonom çalışma | Hayır | Evet (denetimli veya tam) |

<Callout type="info">
2026 itibarıyla organizasyonların büyük çoğunluğu agent'ları pilot veya canlı kullanıyor. LLM'in "sohbet" dönemi yerini "yapar" dönemine bırakıyor.
</Callout>

## Adım 2 — Dört temel bileşen

### 2.1 Plan (Planning)

Agent, büyük bir görevi küçük alt adımlara böler. Örneğin "Bu PDF'i özetle ve Slack'e gönder" görevi şu adımlara ayrılır:

1. PDF'i oku
2. Metni parçalara böl
3. Her parçayı özetle
4. Özetleri birleştir
5. Slack API'sine gönder

Yaygın planlama desenleri (pattern): ReAct (Reason + Act), Plan-and-Execute, Tree of Thoughts.

### 2.2 Araç Kullanımı (Tool Use / Function Calling)

LLM, JSON şemasıyla tanımlanmış harici fonksiyonları çağırabilir. Bu fonksiyonlar: web arama, veritabanı sorgusu, kod çalıştırma, e-posta gönderme gibi her şey olabilir.

```python
tools = [
    {
        "name": "web_search",
        "description": "İnternet araması yapar ve sonuçları döner.",
        "input_schema": {
            "type": "object",
            "properties": {
                "query": {"type": "string", "description": "Arama sorgusu"}
            },
            "required": ["query"]
        }
    }
]
```

### 2.3 Hafıza (Memory)

| Tür | Açıklama | Örnek |
|---|---|---|
| Kısa vadeli | Bağlam penceresi içindeki mesajlar | Sohbet geçmişi |
| Uzun vadeli | Vektör veri tabanı | Şirket dokümanları |
| Epizodik | Oturum özetleri | "Dün yaptıklarım" |
| Prosedürel | Öğrenilen beceriler | Özel komut listeleri |

### 2.4 Yansıma (Reflection)

Agent kendi çıktısını eleştirir ve gerekirse baştan başlar. Basit örnek: Agent bir kod parçası yazar → kodu çalıştırır → hata alır → hatayı okur → düzeltir.

## Adım 3 — Python ortamı kurulumu

```bash
# Sanal ortam oluştur
python -m venv .venv

# Sanal ortamı etkinleştir (Windows PowerShell)
.venv\Scripts\Activate.ps1

# Sanal ortamı etkinleştir (macOS/Linux)
source .venv/bin/activate

# Gerekli paketleri yükle
pip install anthropic python-dotenv
```

Proje kök dizininde `.env` dosyası oluştur:

```
ANTHROPIC_API_KEY=sk-ant-...buraya-anahtarını-yapıştır...
```

## Adım 4 — İlk API çağrısı

```python
import os
from dotenv import load_dotenv
import anthropic

load_dotenv()

client = anthropic.Anthropic(api_key=os.environ["ANTHROPIC_API_KEY"])

message = client.messages.create(
    model="claude-sonnet-4-5",
    max_tokens=256,
    messages=[
        {
            "role": "user",
            "content": "Agentic AI'ı bir cümleyle açıkla."
        }
    ]
)

print(message.content[0].text)
```

Çalıştır:

```bash
python ilk_cagri.py
```

Beklenen çıktı (model yanıtı değişebilir):

```
Agentic AI, bir dil modelini; planlayan, araç kullanan ve döngüsel
geri-beslemeyle görevleri tamamlayan otonom bir sisteme dönüştüren mimaridir.
```

## Adım 5 — Temel kavram haritası

Aşağıdaki yapıyı zihinsel model olarak kullan:

```
Kullanıcı görevi
      │
      ▼
  [Orchestrator / Agent]
   ├── Planlama motoru
   ├── Araç çağırıcısı ──→ [Dış dünya: API, dosya, DB]
   ├── Hafıza yöneticisi ──→ [Vektör DB / context]
   └── Yansıma döngüsü
      │
      ▼
  Tamamlanmış görev
```

Bu mimariyi sonraki modüllerde LangGraph (Modül 04) ve CrewAI (Modül 05) ile somut kod olarak inşa edeceksin.

## Egzersiz

Aşağıdaki görevi tamamla:

1. `sistem_promptu.py` adlı bir dosya oluştur.
2. Claude'a **sistem mesajıyla** şu rolü ver: "Sen bir agentic AI öğretmenisin. Türkçe, kısa ve net yanıt verirsin."
3. Kullanıcı sorusu olarak "Yansıma (reflection) ne işe yarar?" sor.
4. Yanıtı terminale yazdır.

**İpucu:** `client.messages.create()` içinde `system` parametresini kullan.

<details>
<summary>Çözüm (tıkla)</summary>

```python
import os
from dotenv import load_dotenv
import anthropic

load_dotenv()

client = anthropic.Anthropic(api_key=os.environ["ANTHROPIC_API_KEY"])

message = client.messages.create(
    model="claude-sonnet-4-5",
    max_tokens=256,
    system="Sen bir agentic AI öğretmenisin. Türkçe, kısa ve net yanıt verirsin.",
    messages=[
        {
            "role": "user",
            "content": "Yansıma (reflection) ne işe yarar?"
        }
    ]
)

print(message.content[0].text)
```
