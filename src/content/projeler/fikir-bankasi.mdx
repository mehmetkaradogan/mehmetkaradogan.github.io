## Sektöre Göre Fikirler

### Eğitim
- Kişiselleştirilmiş öğrenme yolu oluşturucu
- Otomatik sınav sorusu üreticisi
- Öğrenci geri bildirim analisti

### Sağlık (dikkat: KVKK/GDPR)
- Tıbbi literatür özetleyici (klinik kullanım değil)
- Semptom → triage öneri (yasal sorumluluk notu ile)
- İlaç etkileşim araştırıcı

### Hukuk
- Sözleşme risk işaretleyici
- Mahkeme kararı özetleyici
- Mevzuat takip asistanı

### Finans
- Kazanç raporu analisti
- Haber duygusu → piyasa etkisi ilişkilendirici
- Gider kategorileyici

### Yazılım Geliştirme
- PR özetleyici
- Changelog üreticisi
- Bağımlılık güvenlik tarayıcısı
- Refactoring öneri motoru

## Proje Seçim Rehberi

Hangi projeyi seçeceğini bilmiyorsan şu soruları sor:

1. **Hangi sorunu çözmek istiyorum?** Günlük hayatında tekrar eden ve sıkıcı bulduğun bir görevi düşün.
2. **Hangi modülleri tamamladım?** Modül 01-03 → Başlangıç. Modül 04-06 → Orta. Modül 07-09 → İleri.
3. **Ne kadar zamanım var?** 1 gün → Başlangıç. 1 hafta → Orta. 1 ay → İleri.
4. **Hangi araçlara erişimim var?** Ücretsiz başlamak için: Anthropic API + ChromaDB + yerel Python yeterli.

Proje seçerken "en zor" veya "en etkileyici" olanı seçme. Tamamlayabildiğin ve gerçekten kullandığın proje, yarıda kalan büyük projeye değer.
</Callout>
