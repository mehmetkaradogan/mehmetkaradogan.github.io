## MCP Nedir? (Hızlı Özet)

**MCP (Model Context Protocol — Model Bağlam Protokolü)**, Anthropic'in 2024 sonunda açık kaynak olarak yayınladığı ve 2026 itibarıyla OpenAI, Google ve 200'den fazla topluluk sunucusuyla desteklenen **araç entegrasyon standardıdır**. MCP sayesinde bir agent, standart bir arayüzle farklı servis ve veritabanlarına bağlanır.

MCP sunucuları iki kategoriye ayrılır:

- **Resmi (Official):** Servisin kendisi veya Anthropic/partnerleri tarafından yayınlanır.
- **Topluluk (Community):** Bağımsız geliştiriciler tarafından oluşturulur, kalite değişkendir.

<Callout type="uyari">
Topluluk sunucularını kullanmadan önce kaynak kodunu inceleyin. Güvenilir kaynak: [github.com/modelcontextprotocol/servers](https://github.com/modelcontextprotocol/servers) ve [mcp.so](https://mcp.so/).
</Callout>

## Kurulum Genel Mantığı

Tüm MCP sunucuları Claude Code veya uyumlu istemciye şu yapıyla eklenir:

```json
{
  "mcpServers": {
    "sunucu-adi": {
      "command": "npx | uvx | python",
      "args": ["paket-adi", ...],
      "env": {
        "API_KEY": "..."
      }
    }
  }
}
```

Yapılandırma dosyasının yeri:
- Claude Desktop: `~/.config/Claude/claude_desktop_config.json` (macOS/Linux) veya `%APPDATA%\Claude\claude_desktop_config.json` (Windows).
- Proje bazlı: `.mcp.json` (proje kökünde, Claude Code destekler).

## Sunucu Seçerken Dikkat Edilecekler

<Callout type="uyari">
**Güvenlik:** MCP sunucuları sisteminize ve verilerinize geniş erişim sağlayabilir. Üretim ortamında yalnızca resmi veya iyi incelenmiş topluluk sunucularını kullanın.
</Callout>

| Kriter | Ne Kontrol Edin |
|---|---|
| **Kaynak doğruluğu** | GitHub repo'sunu ve yayıncısını doğrulayın |
| **Son güncelleme** | 6 aydan eski güncellemesiz topluluk sunucularında dikkatli olun |
| **İzin kapsamı** | Sunucunun istediği erişim haklarını inceleyin |
| **Bağımlılıklar** | `npm audit` veya `pip-audit` çalıştırın |
| **Topluluk** | GitHub star sayısı ve açık issue'lar sağlık göstergesidir |
