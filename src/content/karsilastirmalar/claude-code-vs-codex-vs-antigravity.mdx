## Kime Hangisi?

Agentic kodlama (agentic coding) alanında 2026'nın üç büyük oyuncusu farklı felsefeleri temsil ediyor:

- **Claude Code** → Terminal'de yaşıyorsanız, 1M token bağlamla tüm kod tabanını okutmak istiyorsanız, MCP ekosistemini kullanıyorsanız.
- **OpenAI Codex** → Bilgisayar kontrolü (computer use) gerektiren görevler, yapılandırılmış araç çağırma, geniş OpenAI ekosistemiyle entegrasyon.
- **Google Antigravity 2.0** → Gemini ekosisteminde çalışıyorsanız, görsel IDE tercih ediyorsanız, ücretsiz başlangıç için, tarayıcı kontrolüne (browser control) ihtiyaç duyuyorsanız.

<Callout type="not">
Google Antigravity, Kasım 2025'te çıkan ve Mayıs 2026'da 2.0 sürümüyle bağımsız bir agent orchestration masaüstü uygulamasına dönüşen Gemini 3 Pro tabanlı agentic IDE'dir. Eski Gemini CLI'yın resmi halefidir.
</Callout>

## 3 Mini Vaka Çalışması

### Vaka 1: Tek Geliştirici — Büyük Refactoring

Bir geliştirici, 80.000 satırlık bir Python monorepo'yu mikroservislere bölmek istiyor. Tüm kod tabanını anlayan, bağımlılıkları takip eden ve dosyalar arası tutarlı değişiklik yapan bir araç gerekiyor.

**Seçim: Claude Code**

1M token bağlamı sayesinde Claude Code tüm repo'yu okuyabilir. `memory.md` dosyasına mimari kararları kaydeder; bir sonraki oturumda kaldığı yerden devam eder. Terminal'den çalıştığı için CI/CD pipeline'ına kolayca entegre edilir.

```bash
# Proje kökünde başlat
claude

# Claude, CLAUDE.md ve memory.md dosyalarını okur
# Sonra görevi ver:
> Bu repo'daki authentication modülünü bağımsız bir FastAPI servisine ayır.
> Tüm import'ları güncelle, testleri koştur ve değişiklikleri commit et.
```

Claude Code şunları otomatik yapar: ilgili dosyaları tanımlar, bağımlılık haritası çıkarır, değişiklikleri uygular, testleri çalıştırır, başarılıysa commit atar.

---

### Vaka 2: Ürün Ekibi — Web App Test Otomasyonu

Bir ürün ekibi, yeni özelliklerin tarayıcıda gerçekten çalışıp çalışmadığını otomatik test etmek istiyor. Ekran görüntüsü alarak, form doldurup, buton tıklayarak end-to-end test.

**Seçim: OpenAI Codex (Computer Use)**

Codex'in computer use yeteneği tarayıcıyı piksel seviyesinde kontrol eder. Bir UI değiştiğinde script güncellemek yerine Codex "ekranı gör, tıkla" mantığıyla çalışır.

```python
from openai import OpenAI

client = OpenAI()

# Computer use ile tarayıcı kontrolü
response = client.responses.create(
    model="computer-use-preview",
    tools=[{"type": "computer_use_preview"}],
    input=[{
        "role": "user",
        "content": (
            "https://app.example.com adresine git. "
            "Kullanıcı adı 'test@example.com', şifre 'test123' ile giriş yap. "
            "Dashboard'da yeni proje oluştur, adını 'Test Projesi' yap ve kaydet. "
            "İşlemin başarılı olduğunu doğrula."
        )
    }]
)
```

### Vaka 3: Startup — Hızlı Prototip, Gemini Ekosistemi

Küçük bir startup, Gemini API'yi kullanan bir proje üzerinde çalışıyor. Görsel IDE istiyorlar, bireysel geliştiriciler için ücretsiz başlangıç şart, browser kontrolü gerekiyor.

**Seçim: Google Antigravity 2.0**

Antigravity'nin Plan Mode'u görevi adımlara böler ve onay ister. Agent Manager birden fazla ajan çalıştırmayı görselleştirir. Browser tool ile web araştırması ve form doldurma yerleşik olarak gelir. Bireyler için ücretsiz public preview, sıfır başlangıç maliyeti.

<Callout type="ipucu">
Antigravity'de model seçimini dikkatli yapın. Varsayılan Gemini 3 Pro güçlü ama maliyetlidir. Rutin görevler için Claude Sonnet 4.5 veya GPT-OSS ile maliyet düşürülebilir.
</Callout>

## Yanlış Seçimin Maliyeti

**Araç-görev uyumsuzluğu:** Antigravity'yi terminal ağırlıklı CI/CD pipeline'ına entegre etmeye çalışmak ciddi zaman kaybı yaratır; araç bu senaryo için tasarlanmamıştır. Tersine, Claude Code'u browser otomasyon görevleri için kullanmak computer use eklentisi gerektirip orijinal avantajını eritir.

**Bağlam penceresi hatası:** 80.000 satırlık bir kod tabanını 128K token bağlamlı bir araçla analiz etmeye çalışmak, ya kodun bölünmesini ya da kritik bağlamın kaybedilmesini zorunlu kılar. Büyük repo işleri için 1M bağlamlı araçlar tercih edin.

**Ücretsiz plan yanılgısı:** Antigravity'nin ücretsiz public preview'ı cazip görünür; ancak üretim yükleri için ücretli plan farkları ve Gemini 3 Pro token maliyeti hızla birikir. Maliyet modelini baştan netleştirin. Ayrıca bkz. [Model Context Management](/kavramlar/model-context-management).

**MCP ekosistemi kararı:** Claude Code'un MCP native desteği, 200+ MCP sunucusuna (GitHub, Slack, Postgres, Stripe, Figma, Docker) doğrudan erişim sağlar. Codex veya Antigravity ile aynı entegrasyonlar için ek eklenti ve konfigürasyon gerekir. Eğer MCP ağırlıklı bir iş akışı kuruyorsanız bu fark belirleyici olur.

<Callout type="uyari">
Computer use özelliği tüm araçlarda ek maliyet getirir ve standart API çağrısından daha yavaştır. Browser kontrol görevleri için zaman ve maliyet bütçenizi buna göre ayarlayın.
</Callout>
